# 金融 × 知識グラフ × ネットワーク科学：研究領域マップ

**Finance × Knowledge Graph × Network Science: Research Landscape**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 目的

本リポジトリは、**金融（Finance）**、**知識グラフ（Knowledge Graph）**、**ネットワーク科学（Network Science）** の交差領域における研究の全体像を体系的に整理したサーベイ資料です。金融、コンピュータサイエンス、経済学にまたがる研究者・実務家・学生が、グラフベース・ネットワークベースの手法が金融分析・リスク管理・コーポレートガバナンスをどのように変革しているかを理解するためのリファレンスとして設計されています。

## 対象読者

- **研究者** — 金融経済学、計算ファイナンス、ネットワーク科学の分野
- **実務家** — フィンテック、リスク管理、規制コンプライアンスの分野
- **学生** — 金融、CS、経済学、および関連する学際的プログラム
